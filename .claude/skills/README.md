# Skills fuer FahrSync

Anleitungen, die Claude Code in jeder Sitzung in diesem Repository automatisch
zur Verfuegung stehen. Unveraenderte Kopien aus Anthropics frei verfuegbaren
Erweiterungen (Apache-2.0, Lizenz jeweils als LICENSE.txt daneben):

| Skill | Quelle | Wofuer bei FahrSync |
|---|---|---|
| frontend-design | anthropics/claude-plugins-official | Seiten gestalten, die nicht nach Vorlage aussehen |
| design-critique | anthropics/knowledge-work-plugins (design) | Kritik: erster Eindruck, Bedienung, Hierarchie |
| accessibility-review | anthropics/knowledge-work-plugins (design) | Barrierefreiheit nach WCAG 2.1 AA |
| design-system | anthropics/knowledge-work-plugins (design) | Farben, Abstaende, Bausteine vereinheitlichen |
| ux-copy | anthropics/knowledge-work-plugins (design) | Knopf-, Fehler- und Hinweistexte |
| seo-audit | anthropics/knowledge-work-plugins (marketing) | Auffindbarkeit von fahrsync.de |
| content-creation | anthropics/knowledge-work-plugins (marketing) | Instagram, Landingpage, Newsletter |
| brand-review | anthropics/knowledge-work-plugins (marketing) | Einheitlicher Ton, heikle Werbeaussagen |

Der Ordner beginnt mit einem Punkt und wird von GitHub Pages deshalb nicht
auf fahrsync.de veroeffentlicht.
